
[**FastAPI**  ](https://fastapi.tiangolo.com/)
Framework moderno e de alta performance para construção de APIs com Python. Ele fornece validação automática de dados, documentação interativa (Swagger/OpenAPI) e suporte nativo a tipagem.
````
pip install fastapi
````

[**Uvicorn**](https://uvicorn.dev/)  
Servidor ASGI leve e rápido utilizado para executar aplicações FastAPI, garantindo alta performance no tratamento de requisições assíncronas.
````
pip install uvicorn
````

[**python-multipart**  ](https://pypi.org/project/python-multipart/)
Responsável pelo suporte ao envio de arquivos via `multipart/form-data`, essencial para uploads na API.
````
pip install python-multipart
````

[**python-docx**  ](https://python-docx.readthedocs.io/en/latest/)
Permite leitura e manipulação de arquivos Microsoft Word (.docx), incluindo extração de texto e estrutura do documento.
````
pip install python-docx
````

[**odfpy**](https://pypi.org/project/odfpy/)  
Biblioteca para manipulação de arquivos OpenDocument (.odt), possibilitando leitura e extração de conteúdo.
````
pip install odfpy
````

**pypdf**  
Utilizada para leitura e extração de texto de arquivos PDF, além de operações básicas de manipulação.
````
pip install pypdf
````

[**pytest**](https://docs.pytest.org/)
Executa os testes de `test/` (`python -m pytest -v`).
````
pip install pytest
````

Instalar tudo de uma vez:
````
pip install -r requiriments.txt
````
